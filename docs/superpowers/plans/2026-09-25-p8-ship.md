## What P8 is

P8 is the last phase and it has three jobs, in this order. Two are the audit
gaps P5.1 deferred into P8; the third is release hygiene.

### 1. Harness hardening — the pre-tool guard chain (audit G1–G3)

The audit's highest-ROI finding: nothing refuses a *loop* before it happens.
The vault's ranking is explicit — an uncontrolled agent loop is roughly $2 per
30 seconds against ~$0.01 with a circuit breaker — and the fix belongs
**pre-dispatch**, outside the graph, so a refusal costs nothing.

The chain has a fixed order, and each guard can only ever *refuse*:

    budget → circuit → spiral/dedup → context → record

- **Budget** (G3) — per-turn call ceiling plus a per-day token ceiling that
  survives across turns, so a loop cannot spend across sessions. Counters are
  split by kind (input / output / cached / embedding / tool-schema) rather than
  one total, because the vault's point is that they fail differently.
- **Circuit** (G2) — two consecutive failures of the same tool open that tool's
  circuit for the rest of the run (`unavailable — do not retry`); three distinct
  tools failing in one turn escalates the turn. The JEV client already resets
  itself; nothing per-tool did.
- **Spiral/dedup** (G1) — the vault's thresholds: *same tool + normalised args
  ≥3×*, argument **Jaccard > 0.72**, and **>5–10 calls in a turn** when the
  normal is 1–3. Evaluated before dispatch, so the loop is refused, not observed.
- **Context** — a refusal returns the reason *and* what to do instead, because a
  guard that says only "no" teaches the model to retry.

Every verdict is recorded in the turn trace, and CI runs a **runaway simulation
that asserts the refusal** — not that an alert fired.

### 2. Approval integrity (audit G4)

The interrupt carries arguments today but nothing pins them, so an approval can
be replayed and an edited resume is indistinguishable from the original.

- Bind the approval to the **effective digest of the arguments after edits**.
- Guard `tool_call_id` **replay** — one `call_id` may be granted once per thread.
- Refuse to resume a run that is not interrupted (**terminal-state guard**).
- **Fail closed** for side-effecting tools: no digest in the payload, no grant.

Implemented as a pure module (`iris.approval`) with the graph wiring kept thin,
so the invariants are unit-testable without a graph.

### 3. Eval gates with statistics (audit G6)

`scripts/eval_lab.py` reports point estimates. The vault's rule is that a point
estimate with no interval is not a measurement.

- **Noise floor** — repeat a configuration 3–5× and report the spread.
- **Confidence intervals**, not points — Wilson for proportions, bootstrap for
  means; a paired interval for "candidate vs baseline".
- **Sample sizing** — ~63 samples/arm for Δ=0.02 at σ=0.04, computed rather than
  asserted.
- **A frozen holdout** and a **pre-registered decision rule**: the rule is
  written down before the run, and a rule that cannot pass is reported as
  `inconclusive` rather than as a pass.
- **Judge–human agreement** measured before the judgments are trusted (Cohen's
  κ), because a judge nobody calibrated is a random number generator with good
  manners.

Statistics live in `iris.eval.stats` — pure, stdlib-only (`statistics.NormalDist`
for quantiles), unit-tested without Postgres.

### 4. Ship polish

- Packaging verified by CI (`uv build` + the console entry runs), not by reading
  `pyproject.toml`.
- A **version discipline** note and a sample config that actually boots.
- A **support matrix** (Python, OS, providers, Postgres requirement).
- Docs: architecture, quickstart, security notes, phase status.

## Config added (P8)

```python
# Pre-tool guard chain (audit G1–G3)
tool_guard_enabled: bool = True
tool_max_calls_per_turn: int = 8        # normal is 1–3; past this is a loop
tool_spiral_min_repeats: int = 3        # same tool + similar args ≥3×
tool_spiral_jaccard: float = 0.72       # argument similarity that counts as "same"
tool_failure_threshold: int = 2         # consecutive same-tool failures → open circuit
tool_failing_tools_per_turn: int = 3    # distinct failing tools → escalate the turn
budget_max_tokens_per_day: int = 0      # 0 = no ceiling; cross-session spend guard

# Approval integrity (audit G4)
approval_bind_digest: bool = True       # resume must match the effective digest
approval_guard_replay: bool = True      # one call_id grants once per thread
```

## Out of scope (stated, not forgotten)

- A gateway/proxy enforcement tier: Iris is a single process with one owner.
- OpenTelemetry export: the span *fields* matter more than the wire format.
- A Wasm/microVM isolation tier (named in P7 as a prerequisite, not built).
- Canary/shadow traffic splitting: there is no live user base to split.
